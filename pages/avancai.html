Projeto Avançai

O que é o Projeto Avançai?

É um estudo que te prepara para ser membro da Comunhão RARA. Nele você aprenderá:

  • ✓ A nossa visão e profissão de fé
  • ✓ A palavra de Deus
  • ✓ E preparação para o Batismo
Módulo 1

RESET

Esse é o estudo para quem não é batizado. Aqui você aprenderá a visão da nossa igreja, se tornará membro, e ao mesmo tempo será preparado para o batismo.

Começar RESET
Módulo 2

START

Esse é o estudo para quem é batizado. Aqui você aprenderá a visão da nossa igreja e se tornará membro.

Começar START
Etapa Final

CDV

Centro de Despertamento Vocacional. Aqui é a última etapa do Projeto Avançai, depois de concluir o START. Você descobrirá os seus dons para usá-los na obra de Deus.
